# Benchmark: public Gutachten, ground truth and regression

How the [extraction](../services/extractor/README.md) is measured: real PDFs with ground truth, one
stress case per lesson and synthetic layouts ([D34](../docs/11_decisions.md)). Results:
[15 Real results](../docs/15_results_real_pdfs.md).

| File | What it does |
|---|---|
| [`regression.py`](regression.py) | Regression: real PDFs + stress cases + synthetic ones against [`baseline_v4.json`](baseline_v4.json); exits with an error if anything gets worse |
| [`ablation.py`](ablation.py) | Switches off each rule in `RULES` and lists the cases that get worse ([table](ablation_v4.md)) |
| [`perturb.py`](perturb.py) | Variants of the real PDFs (rotated 90°, reduced to 70 %, raster without text) with the same ground truth |
| [`blind_test.py`](blind_test.py) | Blind test: `freeze` freezes the predictions before looking at new PDFs, `score` scores them afterwards |
| [`eval_real.py`](eval_real.py) | Compares v1, the current extraction v4 and (optionally) swissgeol with the ground truth |
| [`screen_corpus.py`](screen_corpus.py) | `--download` downloads the manifest; `--screen` filters pages (vector/scan/Bohrprofil), runs v1 and v4 and writes `report.md` + thumbnails (without ground truth) |
| [`manifest.tsv`](manifest.tsv) | 24 public candidates (B-Pläne, UVP-Verbund, NLWKN, Transparenzportal Hamburg) from 9 Länder: name, Land, procedure, URL, expected content. Reviewed (marked `GEPRUEFT`): the 9 with ground truth; those marked `Runde 4 (blind)` are the next blind round; the rest are unopened |
| [`groundtruth/`](groundtruth/wachenroth.json) | Ground truth of 9 German Gutachten (Wachenroth, Talheim, Halle, Hausham, Rednitzhembach, Triefenstein, Marl, Wesel, Berlin) and 4 Swiss examples from swissgeol (factual data, URL and `sha256` of the PDF) |

## Run

From the repository root:

```bash
python benchmark/regression.py --module services/extractor/prototyp_v4.py \
  --real <pdfs> --stress <folder> --synth <folder> --baseline benchmark/baseline_v4.json
python benchmark/eval_real.py <folder_with_the_pdfs> [<swissgeol_output_folder>]
python benchmark/blind_test.py freeze <new_pdfs> benchmark/frozen/<round>   # push before opening the PDFs
python benchmark/blind_test.py score benchmark/frozen/<round>
python benchmark/screen_corpus.py --download ~/gutachten     # needs network access to the domains
python benchmark/screen_corpus.py --screen ~/gutachten ~/gutachten_report
```

Stress cases and synthetic PDFs are generated by
[`stress_cases.py`](../services/extractor/stress_cases.py) and
[`synth_bohrprofil.py`](../services/extractor/synth_bohrprofil.py); OCR results are cached with
`GEO_OCR_CACHE=<dir>`.

The PDFs are **not** committed (internal use, see
[12 Corpus](../docs/12_public_corpus.md#4-legal-use-of-the-pdfs)); only URL, `sha256` and factual
data. In Claude's cloud environment the municipal websites are blocked by the network policy, so
the PDFs are uploaded by hand.

(v3, v1 and swissgeol depths) and round 4 with the Swiss examples
([v3](https://github.com/martinpazmino/GroundTwin/tree/03be932/spikes/korpus/frozen/runde4_swiss),

`blind_test.py score` still reads those files (key `v3`).

The ablation table [`ablation_v4.md`](ablation_v4.md) is written by `ablation.py` and keeps its
generated (German) wording.
